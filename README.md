# ESP32-BikeGuard-Computer
ESP32 bike computer with anti-theft alarm, adaptive speed filtering, reed switch and BLE CSC sensor support, BLE relay, web dashboard and OTA updates.  \  Велокомпьютер на ESP32 с охранной функцией, адаптивной фильтрацией скорости, поддержкой геркона и BLE CSC-датчика, BLE-ретрансляцией, веб-панелью и OTA-обновлениями.
